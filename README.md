

## IS*T207 ASSG 2

Demo prototype of a fictional car rental company for a school assignment.

### Business process
The routine business events of AZ*om Car Rental is as follows:   
   
- Customer reserves car – via the AZ*om Car Rental website using a credit card 
- Customer rents car at the AZ*om Car Rental office 
- Customer returns car at a designed car park 
- Employee of AZ*om Car Rental inspects the returned car – to ensure no 
damages
- Customer pays final bill – cost of rental and including any damages found 

### Constraints

- Vanilla static HTML/CSS/JS (no frameworks, no PHP)
- Css libraries possible but to clarify case by case

### Requirement

1. Functional implementation of Website for the Car Rental company   
2. Quality of User Interfaces design  
3. Creative features of Website implementation (eg. CSS animation, hosting 
deployment, Mobile deployment, etc. )  

#### Bonus Implementation

Includes creative features like CSS animation, transitions, dark mode, dynamic display, map integration, etc. 

- Deployment of your Website on a hosting server  
- Good UI / UX design quality implementation  
- Implementation of creative features on the website 
- Good design consideration written in Review Report   
- Good Screen Walkthrough video presentation and quality of communication 
- Other creative elements 
- Fully deployed on a public hosting server (e.g., GitHub Pages, Netlify, Vercel).
